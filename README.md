# Кабінетна схема

Розстановка уроків по кабінетах Коломийського ліцею «Коломийська гімназія імені Михайла Грушевського» коли частина кабінетів недоступна (ремонт, опалення тощо). Допоміжний інструмент заступника директора.

Сторінка: https://pastushak.github.io/kabinetna-skhema/

## Що вміє

- **По днях** — сітка «кабінет × урок»: клацніть урок, потім вільний кабінет у тому ж стовпці, і урок переїде туди. Кнопка ↺ повертає урок на місце з розкладу.
- **Кабінет на тиждень**, **Учителі**, **Класи** — розклад кабінету, вчителя чи класу з виділеними змінами. Для вчителя й класу: копіювання готового тексту й фільтр **«Лише зі змінами»**. Для вчителя, класу й кабінету — **завантаження PNG** (для вимкненого кабінету — куди перенесено його уроки).
- **Альтернативи для вчителів** — у режимі «Учителі» для кожного перенесеного уроку показано, які ще кабінети вільні в той самий день і на тому самому уроці; клік по кабінету переносить урок туди.
- **Сховати панель** — згортає ліву панель, щоб таблиця займала всю ширину.
- **Завантаженість** — скільки уроків на тиждень у кожному кабінеті.
- **Кабінети** — у лівій панелі для кожного кабінету один із трьох станів: «Працює», «Вручну» (лише ручне перенесення), «Вимк.» (закритий).
- **Тема** — «Авто», «Світла» або «Темна», перемикач угорі праворуч.
- **Заміна кабінетів** — перенести всі уроки закритого кабінету в один інший або в класні кабінети.
- **Підібрати решту автоматично** — розставляє уроки, що лишилися без кабінету.
- **Основна схема** — затверджена розстановка; її можна повернути одним кліком.

## Збереження і обмін

Схема зберігається в браузері того, хто з нею працює. Щоб передати її колегам:

1. «Експорт схеми в CSV» — завантажує файл (розділювач `;`, UTF-8, відкривається в Excel).
2. Колега натискає «Імпорт схеми з CSV» і обирає цей файл.

## Оновлення розкладу

У «Новій школі»: «Розклад/Заміни» → «За аудиторіями», виділити все (Ctrl+A), скопіювати. На сторінці: «Оновити розклад з «Нової школи»», вставити, «Розібрати», «Застосувати». Переміщення уроків, які не змінилися, зберігаються.
